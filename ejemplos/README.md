# Ejemplos .park

Archivos de ejemplo de la especificación v0.1. Los inválidos incumplen la gramática.

| Archivo | Descripción y resultado esperado |
|---|---|
| `validos/centro_basico.park` | Ejemplo base del proyecto |
| `validos/completo.park` | Usa todas las instrucciones, con un comentario |
| `invalidos/01_clave_desconocida.park` | Usa TARIFAX, una instrucción que no existe |
| `invalidos/03_sin_fin.park` | Falta cerrar con FIN_ESTACIONAMIENTO |
| `invalidos/04_valor_no_numerico.park` | La tarifa está escrita con letras en vez de número |
