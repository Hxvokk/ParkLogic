# ParkLogic

Metalenguaje de dominio específico para definir reglas de cobro de estacionamientos mediante archivos `.park`. Un programa de consola en Python leerá el archivo, lo validará y calculará el importe de una estancia.

**Equipo:** Orlando Medina Guzmán, Edgar Gael Reyes Quevedo, Abisaid Guadalupe Angulo Munguia y Eduardo Borquez Navarrete.

**Metodología:** Scrum. **Estado:** Sprint 1, especificación v0.1. Todavía no hay código del intérprete.
